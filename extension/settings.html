Quick Capture Shortcuts & Context Menu

  • Right-Click Menu: Highlight text on any webpage or embedded PDF, right-click, and choose Save to IPMAT/CUET VOCAB BUILDER.
  • Keyboard Shortcut: Select any word or phrase and press Alt + Shift + V (Option + Shift + V on Mac) or Alt + Shift + S to open the Save card instantly.
  • Customize Shortcut: Open your browser's Extensions Shortcuts page (e.g. chrome://extensions/shortcuts) anytime to rebind it.

Auto-Save to Google Sheets (60-Second Setup)

  1. Open a new Google Sheet at sheets.new (or import the 3-tab starter template from the web app).
  2. In the top menu, click Extensions → Apps Script.
  3. Delete any starter text in the editor, paste the script below, and press Ctrl+S (or Cmd+S) to save.
  4. Click Deploy → New deployment, choose Web app, set Who has access to Anyone, and click Deploy.
  5. Copy the generated Web App URL (ends with /exec), paste it into Google Sheets Auto-Save URL above, click Save Settings, and click Test Google Sheet.

Privacy & Local Storage Notes

        
    
          
  • Your API key and Google Sheets URL are never hardcoded in source files, never exposed to website scripts, and never included in exported JSON or CSV backups.
    • 
          
  • Because this extension has no backend server and stores settings locally in your browser profile, a locally stored API key is not completely protected against someone who has direct access to your computer or extension files. Use this extension for your personal study only.
    • 
          
  • All vocabulary, idioms, and phrasal verbs are stored locally in your browser. Uninstalling the extension may remove your locally stored data, so export a JSON backup from THE VOCAB VAULT periodically.
