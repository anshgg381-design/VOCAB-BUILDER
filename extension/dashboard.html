    Each file has the exact 3 columns (Word / Idiom / Phrasal Verb, Meaning, Example Sentence). Or just open a blank sheet — the Apps Script creates the 3 tabs automatically.

    Step 2 · Deploy Apps Script (60 Seconds)

    1. Open your Google Sheet (or visit sheets.new) and click Extensions → Apps Script.
    2. Clear any starter code, paste the script below, and press Ctrl+S (or Cmd+S).
    3. Click Deploy → New deployment → Web app.
    4. Set Execute as: Me and Who has access: Anyone, then click Deploy & authorise access.
    5. Copy the Web App URL ending in /exec and connect it in Step 3.
